## Project

Arcade Vault is an online platform for playing games and competing for the highest score. The repo is currently the Create Next App scaffold (`app/layout.tsx`, `app/page.tsx` are still template content).

Development follows **Spec Driven Design** using the `/spec` and `/spec-impl` skills from [Klerith/fernando-skills](https://github.com/Klerith/fernando-skills) (installed with `npx skills@latest add Klerith/fernando-skills`). Write a spec before implementing a feature, then implement against it.

The README is in Spanish.

## Stack and conventions

- **Next.js 16.3 (App Router) + React 19.2**. APIs differ from older Next.js versions; consult `node_modules/next/dist/docs/` (`01-app/`, `03-architecture/`, `index.md`) before using Next.js APIs.
- Route props use the globally generated types (e.g. `LayoutProps<"/">`, `PageProps<"/...">`) rather than hand-written prop types. These come from `.next/types`, generated by `next dev`/`next build`.
- **Tailwind CSS v4** via `@tailwindcss/postcss`. There is no `tailwind.config.*`; theme tokens are defined in `app/globals.css` with `@theme inline`, mapping CSS variables (`--background`, `--foreground`, Geist font variables) to Tailwind utilities. Dark mode uses `prefers-color-scheme`.
- Fonts load through `next/font/google` (Geist, Geist Mono) in `app/layout.tsx` and are exposed as CSS variables.
- TypeScript strict mode; import alias `@/*` maps to the repo root.
